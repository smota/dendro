Security & Authority Posture

Counts of explicit source-field observations. Values stay inside a closed vocabulary, with other when the source is outside it. Command text is never stored. A grant is not effective authority. An empty lane is not a measured zero.

All-time counts — window_from/window_to label the snapshot but do not filter.

Environment Layer Audits explicit permission modes, sandbox grant policies, and dangerous command attempts within a strictly closed vocabulary without capturing raw shell commands.

Closed Security Vocabulary Lanes: Evaluates security stance across 6 deterministic dimensions:

Policy & Profile

Configured permission_mode, sandbox_policy, and permission_profile governing agent boundaries.

Grant vs Authority

Recorded approval decisions and prefix permissions. A grant does NOT infer effective authority without explicit verification.

Attempt Categories

Observed dangerous command categories (e.g. force_push, privilege escalation) without persisting raw command strings.

Secret & Command Hygiene

Command line arguments, environment variables, and authentication tokens are strictly omitted from storage.
