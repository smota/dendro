Security & Authority Posture

Counts of explicit source-field observations. Values stay inside a closed vocabulary, with other when the source is outside it. Command text is never stored. A grant is not effective authority. An empty lane is not a measured zero.

All-time counts — window_from/window_to label the snapshot but do not filter.

policy

permission_mode, sandbox_policy, and permission_profile.

grant

permission_decision and approved_prefix_count. A grant does not confer effective authority.

approval

approval_policy. This is an observed field, not a review verdict.

attempt

dangerous_command category and sandbox_override_requested. The command line is omitted.

effective_authority

Not inferred. Without a policy layer the assessment stays not assessed.

effect

Not stored. Absence of an effect row does not mean the action had no effect.
