Environment & Process Resources

Process scope, max RSS, and process attribution from process identities and samples. I14 is CPU deltas and max sampled RSS. I18 counts read, projected, unprojected, and refused sources. This SQL view does not recompute CPU or coverage.

All-time counts — window_from/window_to label the snapshot but do not filter.

Environment Layer Monitors process scope, max resident set size (RSS), and memory allocation across host OS environments without mixing measurement units.

Max RSS by Root and Unit: Each bar visualizes peak observed Resident Set Size (RSS) per host root directory and process harness:

Launched Processes (Purple)

Direct subprocesses spawned by the agent runtime (e.g. bash commands, compiler runs, build tools).

Discovered Processes (Cyan)

Pre-existing host services or background daemons identified within the agent execution workspace.

Strict Unit Separation

RSS memory units are never coerced or mixed across distinct sample scales (bytes vs pages vs KiB).

Process Deduping

Process counts are deduped by root directory, harness, and attribution to avoid inflated process numbers.
