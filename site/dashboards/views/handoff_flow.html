Work Handoff & Rework Friction

Recorded work transfers, rework returns, and wait or execution medians. Counts are queue flow, not token cost or delivered value. Sender actor, receiver actor, and topology boundary fields.

Coordination Layer Maps inter-agent work delegation, return loops, and turnaround latency to detect communication bottlenecks and rework churn across boundaries.

Pairwise Friction Heatmap: Sender actors form rows; receiver actors form columns. Each cell displays handoffs and return rework percentage:

Cyan Cells (Smooth Flow)

Direct forward delegation with 0% rework returns. Work moves forward cleanly between seats without ping-pong bounce.

Amber Cells (Moderate Friction)

Return rate between 1% and 20%. Indicates normal feedback or occasional specification clarification.

Rose Cells (Severe Churn)

Return rate exceeding 20%. Pinpoints repetitive review rejection, test failure bounce, or prompt contract ambiguity.
