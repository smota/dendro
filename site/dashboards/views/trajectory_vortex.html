Trajectory Vortex (I22)

I22 harness.trajectory_vortex. A trip is distance from the cohort, not a cause.

Model Harness Coordination Environment

Harness computes the trip from turn vectors. Coordination is the session that orbits. Model prices and Environment grants are not inputs.

Each session is a moving point in a sketch of what it has been doing. Completed work falls inward, along an emerald or cyan spiral, into the glowing Convergence Core. That core is the Task Resolution Sink: the cluster of sessions that finished without getting stuck on themselves.

A vortex session does not fall in. It keeps a rose or amber elliptical orbit. Bigger orbits mean a higher self-transition rate or a larger cosine distance from the cohort. Bigger nodes mean more turns. The orbit is a distance signal. It is not a cause, and it does not stop the agent.

Hover or click a node to freeze the motion and read that session. Use the filter to keep every trajectory, only the orbits, or only the spirals that are still converging.

Analyzer 1.0.0, frozen with the Rust tripwire (the SQL trigger only marks the session dirty):
  k = 3 consecutive turns
  self-transition rate = identical consecutive pairs / pairs in the window
  identical = cosine distance ≤ 1e-9
  self-window holds when that rate > 0.5
  centroid = mean vector of untripped sessions
  distance threshold = quantile_cont(reference distances, 0.95)
  trip when cosine_distance(session, centroid) > threshold AND the self-window holds
  cohort minimum = 5 untripped sessions, else status Refused, reason insufficient_sample
  zero vectors are capability_class_other and are not trip fuel
A trip is a cohort distance signal and not a cause.

Console encoding (visual only, not a second analyzer):
  vortex orbit when tripped is true, OR self_transition_rate ≥ 0.5, OR turn_k ≥ 8
  magnitude = 0.55·clamp(rate, 0, 1) + 0.45·clamp(cosine_distance, 0, 1)
  orbit radius grows with magnitude
  node radius grows with sqrt(turn_k)
  rose when tripped or rate ≥ 0.75, otherwise amber
