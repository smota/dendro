Get Started

Inspect your existing AI sessions in 60 seconds.

Dendro reads the local session footprints your coding agents have already written on disk. Zero runtime proxies to configure, zero cloud accounts to create, and zero prompt or secret persistence.

1 · Install or Build the Rust CLI

Install via Cargo or build from Git checkout

Get the single Rust binary locally on Linux, macOS, or WSL2:

# Path A: Install via Cargo (dendro on PATH)
cargo install --git https://github.com/smota/dendro.git dendro-cli
dendro

# (or from local checkout: cargo install --path crates/dendro-cli --locked)

# Path B: Or build and run from Git checkout (current)
git clone https://github.com/smota/dendro.git
cd dendro
cargo build --release --locked
./target/release/dendro
2 · Ratatui Cockpit or Web Studio

Launch the 6-screen TUI or Loopback Hub

Explore in your terminal or serve the Connected Web Studio on loopback (127.0.0.1:4242):

# Launch the 6-screen Ratatui TUI Cockpit
dendro cockpit

# Serve Connected Studio on loopback only
dendro dashboard --serve 127.0.0.1:4242 --site-dir ./site
3 · Advise, Ask & Export

Pre-flight checks, Nao queries & offline reports

Run sub-15ms pre-flight checks, deterministic semantic queries, or privacy-scrubbed exports:

# Sub-15ms pre-flight health oracle
dendro advise

# Deterministic Nao semantic query
dendro ask "top cost by model this week"

Frequently Asked Questions

Architecture, privacy & harness compatibility.

Does Dendro ever persist or transmit my prompts, model responses, or secrets?

Never. Dendro runs 100% locally against an embedded columnar DuckDB store. Prompts, model responses, chain-of-thought, tool arguments, and error payloads are excluded by design, and secret prefixes (sk-, ghp_, gho_, xai-, Bearer tokens) are redacted before storage. When exporting an offline HTML report, actor labels are aliased to Actor 1, Actor 2, etc.

Do I need to wrap my coding agents or install runtime proxies before sessions run?

No. Dendro is a passive out-of-band flight recorder. It discovers and reads the standard session footprints that Claude Code, OpenAI Codex, Google AGY, xAI Grok CLI, and Pi already write to disk.

How do multi-agent orchestrators and SDLC frameworks fit into Dendro's data model?

Dendro treats Fleets, Harnesses, Sessions, Actors, Tools, and Capabilities as the universal primary taxonomy across any coding workflow. Multi-agent orchestrators, SDLC role routers, and worktree supervisors are supported as optional adapters when correlating multi-actor handoff chains, role gates, and isolated worktree runs.
