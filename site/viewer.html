Seat handoff flow

Supported JSON and privacy boundaries

Accepts Dendro report envelopes with payload containing product: "AI Fleet Intelligence", or trace objects with metric_id and inputs. Uses only numeric fields from m1_by_seat, activity, activity_events, handoff_members, handoff_edges, m2_pairs, pair_medians, token_categories, fleet_concurrency, context_compactions.events, m2_pairs, ring_boundaries.edges, task_intake_overhead and ISO from/to or window.from/to. Absent fields remain unavailable. Maximum file size: 10 MiB; maximum 50,000 rows per supported array.

Only load sanitized analytical exports. Raw files stay in browser memory and are not uploaded or stored. Aliases hide labels in the view; this viewer does not sanitize the original file for redistribution. Embedded exports must be scrubbed by the exporter before sharing. No source replay, tool execution spans, mission-token links are inferred from aggregate reports.
