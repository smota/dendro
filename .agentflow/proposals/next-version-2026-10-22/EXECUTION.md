## Checkpoint, resume and retries

Worker execution identity uses `unique_worker_run_id` plus native_client_session_id when exposed. If unavailable, use a factual dispatcher launch receipt (PID/start/sanitized command/input/output/authorship digests), explicitly native_session_id unavailable; harness-managed workers identify actual task/dispatcher receipt without inventing a CLI PID/session. Identity is supported by launch/harness receipts; record the nonsecret client account label only as context, never credentials. A shared authenticated subscription/account is allowed and is not a worker identity. Role strings, model names and provider families alone cannot establish independence. Bind every oracle/build/review action to that execution identity and immutable input/output/authorship artifact digests in the append-only custody ledger. T20 QA execution IDs must be disjoint from every execution ID that authored any tested module or standing-owner integration artifact; the independent reviewer checks those joins and rejects reused/missing IDs or unexplained authorship. New session/run labels cannot erase predecessor authorship.

At every task/review/rework boundary record task and attempt IDs, candidate SHA or uncommitted tree digest, baseline/input/source generations, output/oracle digests, observed runtime/model/provider/effort, worker identity, lease/fence/expiry, run/epoch/custody, tests and exit codes, findings, next action and authenticated return route. Keep failed evidence. A process heartbeat is not authority.

Resume verifies custody owner, fence, source generations, oracle/input digests, working tree and current policy. Stale leases or concurrent owners park execution. Quota exhaustion preserves checkpoint and selects only an authorized eligible task-scoped route; unavailable eligible route parks. Transient transport/rate failures permit at most two retries after 30s then 60s, without altering inputs. Semantic/test failures allow at most two rework rounds after the initial candidate, each independently reviewed. Third failure, privacy leak, source mutation, scope escape, oracle drift, authority uncertainty or budget exception stops that task and blocks affected descendants. Continue only independent admitted tasks. Never hide a failed mandatory acceptance by deleting its question or parser.
