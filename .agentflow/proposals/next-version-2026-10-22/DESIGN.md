# Dendro v0.8.0 design contract

All normative statements below describe proposed delivery. Database schema 4 and domain, answer and contribution contracts `1.0.0` are targets, not changes performed. Lead decisions adjudicate scout disagreements. The supplied source audit is evidence of the pinned baseline, not proof of current runtime adoption.

## 2. Normative records, keys and constraints

Use typed Rust structs/enums and relational tables, not universal entity/attribute/value records. Required fields cannot be filled with display-name sentinels. `Option<T>` means evidence absent; an explicit unsupported reason belongs in Coverage. Unknown enum values are quarantined with counts, never mapped to success. UTC timestamps use signed microseconds; monotonic durations use unsigned microseconds with a same-clock identity. Counts use checked `u64`; currency uses canonical exact rational decimal amounts (integer coefficient and positive decimal scale denominator, currency code), checked arithmetic and overflow refusal. Ratios/allocations retain exact reduced numerator/denominator. Before equality, fact-revision comparison, serialization and hashing, normalize decimal amounts by stripping trailing decimal zeros to the minimal positive power-of-ten denominator; zero is always 0/1, sign belongs only to numerator. USD10/100 and USD1/10 are the same canonical amount1/10, including under the same source key/revision. Preserve source precision; never force ISO display scale into canonical storage. Reduced rational ratios retain numerator/denominator. Only display rounds, half-even to a declared currency/quantity scale; canonical digests never round.

Every fact carries `fact_id`, `source_instance_id`, `source_generation`, `source_key`, `source_schema_id/version`, `parser_id/version`, `event_time?`, `event_sequence?`, `clock_id?` (unknown explicit), `clock_error_us?`, `observed_at`, `ingested_at`, `granularity`, `evidence_ids[]`, `revision`, `supersedes?`, `retracts?`. IDs are domain-tagged HMAC digests of length-delimited canonical tuples, with algorithm/key-id recorded. Source instance is an authority namespace plus producer incarnation, not a directory name. `source_key` is stable within a generation; a new generation retains predecessor evidence. Same bytes in a replaced file do not automatically establish cross-generation equivalence.

Evidence stores safe locator tokens, producer/version, artifact digest, projection recipe and trust label. No raw path, transcript, argv, payload or secret is retained to make a citation convenient. Digests authenticate bytes, not truth. Safe local resolution can reveal an authorized locator without exporting it.

Child lifetime/model/harness/environment may differ from its caller. OpenRig rig/seat/mission IDs and native queue relations remain typed adapter bindings, including collisions; names cannot confer identity or authority.

### Closed WorkEdge contract (relationship-contract-v1)

Endpoints reference typed assignments/attempts/work, never bare display labels. All edges require a source-native relationship key, source authority, evidence IDs and observed/event boundary; absent/truncated/conflict records preserve evidence but are ineligible for reachability. Missing endpoints stay unresolved. Event order is source-sequence-local plus clock bounds; uncertain cross-source order does not assert causality.

| Kind | Endpoints, cardinality and time | Cycle and inclusive-accounting eligibility |
|---|---|---|
| spawn | creator assignment/attempt -> newly created executor assignment/attempt for the same or explicitly linked child work; one evidenced creator per spawned attempt, creator event no later than child creation when comparable; conflicting creators mark conflict | Acyclic attempt lineage. Only its bound target assignment/activity belongs to inclusive closure. |
| delegate_existing | caller assignment -> existing executor assignment for an explicit work relation; many callers and many workers allowed; event within caller assignment, execution may outlive caller | Acyclic work-bound accounting closure; repeated durable worker identities alone are not cycles. Eligible only for target assignment, never whole conversation. |
| handoff | source assignment -> successor assignment, explicit work transfer and transition time; many historical transfers, one claimed transfer transition per source event | History may revisit participants. Does not expand inclusive closure; explicit work/assignment membership may independently place usage in scope. |
| return | executor assignment -> caller assignment with correlation to delegation/spawn; zero/many progress/final receipts, source completion/result boundary | Interaction cycles legal; never expands inclusive closure back to caller. |
| join | waiting assignment -> one or more child assignments with explicit join receipt/time | No ownership or descendant expansion; interaction cycles do not taint spawn DAG. |
| retry | prior attempt -> distinct evidenced later attempt for same work; zero/many successors, causal order required where known | Acyclic attempt succession; no descendant closure, same-work membership selects attempts explicitly. |
| resume | prior segment -> later segment of same attempt if continuation proven; otherwise unresolved, not fabricated retry | Acyclic ordered segments, not new attempt or inclusive expansion. |
| dependency | prerequisite work -> dependent work; many-to-many, declared validity and satisfaction transitions separate | Acyclic work dependencies; never cost reachability or proof of completion. |

Inclusive(v) starts with v's assignment-bound direct observations and follows only evidenced `spawn`/`delegate_existing` target closures. Attach usage to an assignment only with source-backed attempt/interval membership; a straddling aggregate cannot be prorated from elapsed time. Ambiguous membership goes to shared/unattributed scope. Shared descendant observations are set-unioned once. Cyclic eligible closure quarantines affected inclusive folds while independent direct totals survive; never condense cycles into a quietly accepted sum. A diamond uses P spawning A/B, then A and B delegating to the same existing D assignment: D has at most one separate spawn origin. No return/join/handoff closure imports an entire persistent session.

Corrections are append-only revisions. Same revision and digest is idempotent; same revision with different content is conflict. Retractions reference exact prior facts. An answer takes `(event_window, knowledge_cutoff, revision_policy)`; the sole v1 revision policy is `corrections_at_cutoff_v1` (F22). it uses only revisions ingested by cutoff, then applies valid corrections/retractions. An event arriving tomorrow cannot alter yesterday's reproducible answer. Invalid timestamps are retained as rejected evidence counters, not clamped to zero.

Coverage has independent axes: discovery `present`, `absent`, `unauthorized`, `unknown`; read `complete`, `partial`, `failed`, `not_attempted`; projection `supported`, `unsupported_schema`, `recognized_unprojected`. A complete scan with no eligible facts can yield observed zero. No known expected denominator means counts and gap reasons, not a fabricated completeness percentage. Parse acceptance fraction is labeled acceptance of encountered records, not total sensor coverage.

## 3. Capture and sensor admission

`dendro.capture.contribution/v1` declares source/schema versions, capture mode, record-kind mapping, produced fact types/grains, path containment, limits, counter semantics, unsupported kinds, privacy projection, trust mechanism and fixture digests. Each B01-admitted adapter descriptor specifies its own line/record-byte, nesting, batch and carryover bounds; T05 enforces these, not AGY-specific numbers on every source. The global hostile ceiling is 8 MiB encoded bytes per logical input record, nesting depth64, and 1024 decoded records per transaction/batch (larger appends are streamed as successive bounded batches); a descriptor may only tighten these bounds. Oversize/overdeep records are safely skipped/quarantined with partial coverage and reason counts, never silently zero or valid by default. A 1.5MiB native record is admissible only if its real pinned schema/descriptor admits that size; no such format claim is made here. Compile-time registration plus dispatch integration and conformance tests are mandatory. Trusted compiled adapters are not sandboxed by their descriptor. Unknown schema majors stop projection for that source; other admitted sources can continue with visible partial coverage.

AGY export envelope requires contract/version, source instance/incarnation, record key/seq, time/clock, kind and typed payload. Kinds are participant, conversation, message, attempt, binding, invocation, usage, capability_definition, capability_state, action, work_assignment, work_edge and outcome. Unknown required keys/major versions reject; optional unknown fields are ignored with counters and never persisted as text. Per-line limit 1 MiB, batches <=128 records, explicit EOF/truncation, namespace/unit/counter checks. The adapter reads files end-to-end and incremental append, including genuine no-usage exports; it is not a generic callback placeholder. Third-party production of that export is outside the native-format claim, not outside tested import delivery.

Collector process identity includes start ticks to defeat PID reuse. It measures CPU user/system deltas, sampled RSS/peak-of-samples, accessible resource limits, namespace equality and process ancestry within bound scope. It records permission failures, process exit, counter reset and clock basis. PID descendants enter only under an explicit bounded ancestry policy and are revalidated before every sample. Linux host boot identity is privately sealed; WSL placement may be declared unless verified. Namespace IDs show configuration relationships, not proof of inaccessible resources. CPU accounting excludes overlapping parent-inclusive counters; inaccessible children yield partial data.

Syscall processing is transient and bounded: identify call/return and PID/time, discard argument bodies immediately, retain only allowlisted operation/status/count/resource class, plus duration if evidenced. Never retain raw paths, descriptors' targets, argv, network payloads or trace lines. Reject overlong/unparseable records with safe reason codes; unfinished/resumed calls require matching identity, not guessed success. Original traces remain producer-owned outside Dendro retention. T11 must demonstrate a short-lived synthetic authorized Linux process through the admitted real trace reader; T26 must ingest a genuine controlled Windows trace produced for a bound synthetic process and frozen provider profile. Missing required tracer/specimen/authority parks release with a scoped acquisition/remedy task, never a pass or a platform waiver. No install or privileged attachment is implied.

## 4. Accounting, time, cost and outcomes

Canonical fleet usage is the sum of distinct direct observation components after exact evidenced equivalence and revision selection. Provider request keys are `(authority, source_instance/incarnation, native_id)`; cross-source equivalence requires explicit evidence. Possible overlapping rows without proof remain separate observations with an overlap warning; a potentially overlapping fleet total is refused, while scoped nonoverlapping totals remain available. Valid usage without invocation IDs is not dropped. Invocation count is a different population.

Token components distinguish input-uncached, cache-write, cache-read, output and reasoning with inclusion flags `exclusive`, `included_in(component)`, `unknown`. Derived total tokens require compatible component semantics; a literal source-reported total remains displayable at its own grain with definition_unknown even when component inclusion is unknown. For modern input100 plus legacy unknown input, observed-subset100 is valid but full input total remains unknown. For input=100 including cache-read=40 and output=20, total is 120, not 160. Unknown inclusion refuses a total while preserving component values. Cumulative readings 100 then 150 produce delta 50 only for the same proved counter/incarnation/component semantics. A first reading is retained as an observed cumulative amount; its incremental baseline is unknown unless the source explicitly attests since-zero/reset initialization. A decrease alone is conflict/unknown delta, not proof of reset; reset/incarnation evidence is required, and new-file generation alone does not prove reset. No negative delta or invented first-sample consumption.

For node v, inclusive usage is the union of direct observation IDs on v and its evidenced reachable descendants. In a diamond P spawns A/B and A/B delegate_existing to the same work-bound D assignment with one token each, inclusive(P)=4; inclusive(A)+inclusive(B)+direct(P)=5 is forbidden as fleet total. Incomplete lineage can yield a labeled observed lower bound for nonnegative deduplicated facts; otherwise refuse. Inclusive views are nonadditive across roots. Shared worker W with 1000 tokens and two callers stays 1000 in the shared bucket. Evidenced weights .6/.3 allocate 600/300 with residual 100; .7/.4 rejects. Weights use exact rational numerator/denominator arithmetic, with deterministic rounding only for display; allocations plus residual equal the original exact amount. Partial allocation may name only some beneficiaries: the residual remains unallocated and is never assigned to omitted callers. Reachability and wall overlap do not establish ownership. A handoff-straddling usage interval remains on its observed worker, with owner attribution unresolved unless source evidence splits it.

Time windows are half-open `[a,b)`. Geometric intersection with the query window applies only to duration intervals (I10 and I12 elapsed/wall measures). Atomic usage, currency and event-count observations are never prorated by elapsed time: if an evidenced attribution event timestamp exists, use only that timestamp: include the whole amount when it is in [a,b), and exclude it when outside, with no fallback to interval containment. Only when no evidenced attribution timestamp exists may a fully-contained evidence interval determine inclusion. An interval straddling the query window with no such timestamp is excluded from window totals as `straddle_unsplit`, with partial coverage/excluded counts and source-grain amount preserved. Unknown event time and absent interval cannot be guessed into a window. Example100 tokens over [0,10) queried at [0,5) without an evidenced attribution timestamp -> no amount included, excluded100/straddle_unsplit, never50 or measured zero. An evidenced attribution timestamp4 instead includes the whole100; timestamp5 excludes it by half-open rule. Assignment membership ambiguity remains shared/unattributed independently of window eligibility. Wall is interval-union length; summed execution is the sum of distinct attempt activity-segment lengths. `[0,10)` and `[0,10)` yield wall=10s, summed=20 attempt-seconds, average concurrency=2. `[0,10)` plus `[10,12)` yields wall=sum=12; overlap `[9,12)` instead yields wall=12,sum=13. Summed duration is never inferred from tree depth. Right-censored duration through cutoff requires explicit ongoing/liveness evidence covering that cutoff, itself ingested by the knowledge cutoff. A lone start with no end does not prove survival: report missing_end, supported observed extent if any, and unknown completed duration. A later liveness report cannot leak into a sealed prior snapshot. Cross-clock order uses source-local sequence and error bounds; end<start is conflict, not zero. Parent `[0,5)`, child `[4,20)` gives parent wall=5 and lineage-close wall=20; child outliving parent is valid.

Observed currency survives without a rate card and is labeled observed, with currency/source scope. Estimated cost uses versioned provider/model/component/time prices, never a display name or total-token shortcut. Example 1000 input at $2/million plus 500 output at $8/million = $0.006 estimated. Mixed currencies do not sum without an explicit dated conversion policy. Subscription spend is a separate period-level fact, not token price. Never add observed and estimated amounts for the same population; prefer observed where comparable, show unmatched estimates separately.

Outcome rules evaluate source-backed transitions at cutoff. Attempt success is not work acceptance. Three attempts costing $10 each with two successes have cost/success = $30/2=$15. The separately named mean cost among successful attempts is $10, a legitimate different population. Work completed but review pending has acceptance unknown; later acceptance can be revoked or superseded. Missing outcome denominators refuse a success rate; closed observed attempts can still have a documented descriptive ratio. A source-backed accepted-work rule must list eligible evidence and precedence, not default to any successful retry. Missing acceptance receipt is not_recorded/unknown unless a closed-world ruleset proves nonacceptance. A named mean-of-ratios must disclose the positive-denominator population, exclusions and undefined count; it may not silently average undefined terms. Ratio-of-sums with zero aggregate denominator refuses.

## 5. Insight registry and shared answers

`dendro.insight.contribution/v1` is a compile-time registry of Measure, Analyzer and Question descriptors plus conformance vectors. Measure fields: id/semver/domain/question, quantity/unit/grain, population predicate/hash, denominator predicate, window/clock, missingness, dedup key, accounting, aggregation and forbidden combinations. Denominator/unit/population/identity/accounting changes require a major measure version. Domain, source schema, contribution, analyzer, answer and rate-card versions remain independently recorded.

Analyzer fields: id/semver, pinned measure versions, exact algorithm, required fact/field/grain, assumptions and their checks, exclusions, uncertainty model, refusal codes, comparison prerequisites and non-claims. The reference pack is descriptive: no significance claims, p-values or arbitrary confidence scores. A future inferential contribution must declare sampling/cluster unit, supported model, multiplicity treatment and independent coverage before admission. Named mean-of-ratios is allowed when its population and zero-denominator handling are explicit.

Answer `1.0.0` contains question/query hash, cutoff/window, status `supported`, `partial`, `refused`, `not_observable`, `noncomparable`, `threshold_exceeded`, canonical typed values, units, measure/analyzer versions, accounting, population/denominator, coverage IDs and counts, exclusions, uncertainty (`exact_for_observed`, `observed_lower_bound`, `allocated`, `unknown`), assumptions, alternative explanations, evidence IDs, method/formula, trust, non-claims and separate hypotheses. `NOT_ASSESSED` is a policy-evaluation state within the answer, never a zero violation count. Threshold status requires a configured threshold; exploratory screens disclose family size without significance language.

The following actual reference definitions ship at measure/analyzer version `1.0.0`. All use the common cutoff/dedup rules above; each row names additional conditions and refusal behavior. No presenter recomputes these values.

## 7. Security and privacy boundaries

Source ingest is read-only and root-contained with canonical/symlink cycle checks, private snapshots, bounded readers and output/lock/sidecar alias defense. Parameterize SQL; Nao chooses typed intents, never generated SQL. Answer-query connections are read-only, external access disabled, allowlisted views/typed parameterized queries only, bounded rows/time; prohibit ATTACH, COPY, file/URL/network readers and dynamic SQL from answer paths. Strip C0/C1 controls and ANSI/OSC sequences, including clipboard OSC52, from all source labels/error strings. HTML-escape by default, enforce strict CSP and never construct inline executable script from source content. Deny unsafe Rust. Avoid blocking Tokio: bounded queues and blocking-worker I/O; debounce watcher changes at 1500ms; watch only admitted read-only source roots. Contributions are trusted compiled code reviewed with the binary, not remotely loaded executables.

Project before persistence: allowlisted enums, numeric fields, approved safe model/capability identifiers, private labels and HMAC fingerprints. Parse bounded transient command bytes only when needed for safe classification; discard payloads before emitting facts. Redaction is defense in depth. No auth files, environ, raw argv/transcript/path/payload, PEM/JWT body or arbitrary warning text is stored/exported. Privacy keys are private permission-restricted sidecars, never in answers or release evidence. Missing key prevents correlating private identifiers; it never triggers silent rekeying or plaintext fallback. Authenticated imports verify signatures against configured trust roots only; absent signature stays unverified, without implying fabrication. Signed producer assertions stay unverified unless the configured source-verification mechanism actually verifies them; no signing/key provisioning system is implied. A privacy incident stops affected ingest/export, quarantines outputs and proposes provenance-scoped remediation with disposition of DBs, backups, caches and key copies under applicable authority; no automatic broad deletion. Resource and parser limits cover hostile nesting, duplicate keys, decompression and high-cardinality labels; no unbounded retained raw payloads.
