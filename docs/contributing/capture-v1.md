# Compile-time capture contributions v1

T05 provides bounded JSONL capture and compile-time registration. Contributions are trusted compiled Rust modules, not sandboxed or dynamically loaded plugins. This source API does not grant source/profile admission or publication authority. Existing production dispatch integration is owned by the adapter and routing tasks (T06-T11/T18); this example runs through the registry API directly.

Run from the repository root on a supported native runner:

```powershell
cargo test -p dendro-connectors --test registry_v080 --locked
cargo run -p dendro-connectors --example capture_v1 --locked -- examples/capture-v1 sample.jsonl
```

The example prints `read=Complete projected=1 unprojected=1 reasons=[]` and `amounts=[1]`. It captures a synthetic integer, not model-token usage. Its projected fact is an existing Rust integer; it neither introduces core fact types nor persists arbitrary source text.

## Contribution and standing registration

Copy `examples/capture-v1/contribution.rs` into a new contribution module. Declare a static `Descriptor`, implement `Contribution`, and ask the standing owner to add the descriptor to a static registration slice. `Registry::new` validates that slice before lookup; `Registry::capture` requires the contribution descriptor to match its standing registration. The free `capture` function is a trusted lower-level conformance API and does not establish standing registration. The example demonstrates this exact standing registration. The reader takes an explicitly selected directory and a direct `.jsonl` child, a compiled contribution and a mutable `Cursor`. No HOME discovery is implied.

Descriptors separately declare contribution contract/version, source id/schema, capture mode, record kinds, fact grains, privacy projection, trust, conformance-fixture digest and bounds. The v1 SDK mandates direct-child canonical containment, LF or CRLF framing (all framing bytes count), held trailing partials excluded from both batch and hash, and the counter/unsupported rules below. Additional framing requires a separately reviewed reader; it cannot silently reuse the JSONL contract.

`Descriptor::validate` refuses incompatible contract majors (`dendro.capture.contribution/0` or `/2`), dynamic loading, missing/invalid fixture digests, a digest that does not match the descriptor's static fixture bytes, and unsafe limits. This binds conformance input bytes only; trusted compiled declarations are not independent proof of producer/profile admission. Standing-owner review still owns native admission. A descriptor may only tighten 8,388,608 encoded bytes per record, container depth 64, and 1,024 decoded records per batch. Scalars have depth 0; keys add no depth. Export sources preserve 1,048,576 encoded bytes and 128 line attempts. AGY bounds are 1,048,576 bytes and 128 decoded records; no AGY vendor grammar is claimed here. Collectors additionally retain max 64 bound processes and 600 samples; these bounds alone admit no producer specimen. `native_size_admitted` rejects a 1.5 MiB native record absent an admitted producer descriptor. The global hostile ceiling itself grants no native format admission.

The example tightens these bounds to 1 MiB, depth 8 and 16 decoded records. Its frozen fixture digest is SHA-256 of the exact projected-1 example record including LF. Only the two declared example kinds are recognized. Unknown shapes/kinds are counted outside recognized and produce partial coverage with the closed `unsupported_schema` reason. A declared example record whose `n` is not a representable i64 integer is quarantined, with partial coverage and the closed `malformed-json-record` diagnostic; it is still decoded JSON, and is not counted as a recognized record. Unknown fields count toward `ignored_unknown_field` and their values are discarded. Keep all projection output structured and allowlisted. Trusted contribution code is responsible for projecting to existing admitted core fact types before storage; the generic SDK does not make arbitrary Rust return types safe to persist.

## Streaming, counters and coverage

Each capture invocation reads at most its decoded-record batch limit (and any tighter line-attempt limit). Successive invocations resume from the hashed committed byte prefix. Every batch additionally has an aggregate body-input budget of 8,388,609 bytes and at most min(declared line attempts or decoded-record limit, 1024) attempts. `Some(0)` is refused. This bounds malformed-only and whitespace-only batches as well as accepted input retention. `Value` structures, line/scratch buffers and a small reader buffer add bounded representation overhead; the input budget is not a claim of an exact heap-byte cap. Prefix verification remains streaming but can revisit earlier committed bytes. An overlong delimited line within this budget is drained with bounded scratch space, counted as quarantined and never parsed or returned. A tail that reaches EOF or the batch byte budget before its delimiter stays uncommitted. An already valid prefix and its hash remain available as a partial batch; an oversized first attempt may fail with the existing closed export diagnostic. The reader checks byte size before depth and depth before duplicate-key decoding. Quarantine and malformed diagnostics contain closed static codes and no record text. The raw input is transient only.

`recognized = projected + recognized_unprojected`; decoded also includes unsupported-major records, while malformed and quarantined records are counted separately. A schema field incompatible with the registered schema stops that source immediately, counts the unsupported record exactly once in the invocation and leaves later records unobserved. Its raw read position differs from the committed watermark, which remains before the unsupported record. A different source can continue with its own cursor.

Preserve the cursor across batches to retain earlier malformed/quarantined/unsupported coverage. An empty later batch cannot erase earlier defects. Persisting cursor coverage and atomic storage/watermark publication is the integrating caller's responsibility. The cursor records a schema stop. Repeated invocations return partial without re-reading or incrementing unsupported/decoded counts. After an admitted adapter upgrade, explicitly clear `stopped_schema` or create a new cursor at the retained watermark to retry that record.

Observed zero requires present discovery, complete admitted reading, no prior/current malformed, quarantined, unrecognized or unsupported records, and no decoded records in the scoped read. It establishes only zero captured/projected records in that scope. It never establishes zero model usage, activity, cost or security events. Missing roots are absent/not_attempted; failed resumes are failed; held partials and interrupted batches are partial. Discovery of nonempty directories alone makes no completeness claim.

Grok has a scoped source contract for two exact frozen fixture digests; native parser acceptance remains T08. Its internal availability is typed `ParserPending`, while the persisted closed refusal is `source_not_admitted`, without advancing a watermark. AGY and future environment/trace modules also claim no empty successful parser. Linux strace and Windows ETW source contracts remain blocked pending their required evidence. Do not enroll pending/blocked descriptors as implemented.

## Independent conformance

`registry_v080` verifies the immutable frozen oracle hash and dispatches all 34 vector IDs, including generative byte/hash fixtures, CRLF framing, Unicode byte boundaries, depth 8/9 and 64/65, duplicate keys, all global-limit variants, bounded resume, version/source refusal and safe errors. The required native symlink subcase fails the gate with `not_attempted` if the host cannot create its fixture; it never silently passes. Cancellation has typed `ReadState::Interrupted`, retains no newly committed watermark and does not become an unavailable-source diagnostic. Missing roots are absent/not_attempted on both discovery and capture. Native Linux, broader release acceptance and independent review remain separate gates.
