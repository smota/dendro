## Outcome and unchanged definitions

The operator uses existing public report and trace journeys with the same
database/rig/UTC filters. For every detected episode, trace shows ordered member
observations, safe equality identifiers, outcomes/timestamps, source keys and
producing generations, and an explicitly identified qualifying consecutive
triple/span. Include enough safe scoped input and run-breaking evidence to
independently derive episodes/counts, not merely trust a claimed membership
list. Pin null/unknown/linkage and zero-episode/unsupported cases; absence of
traceable evidence must not become a silent no-loop claim.

Preserve K11: sliding consecutive triples, inclusive600seconds, one whole-run
episode with full failure count, breaks, session/seat separation and missing
time treatment. Preserve #40's separate Codex command_execution versus unread
seat tool_call unit, exact keyed lexical equality, source-order/untimed anchors,
window filtering and applied coverage. No inferred wrapper join or output-text
outcome. Existing Claude/Pi rules, counts and report meanings stay unchanged.
Recompute episode set, each full-run count and any displayed loop aggregate
from trace alone, with no access to raw logs, local key or candidate detector.
Architecture owns shared implementation; do not create a new conflicting rule.

Use keyed opaque equality evidence only, preserving AC10 nonreproducibility
without the local key. Never expose raw command/input/prompt/output, key bytes,
reversible encodings or unfiltered source bodies. Safe source references must
identify records/generations and ingestion provenance without dumping content.
Unknown or unavailable source/link/time evidence stays explicit; no guessed
generation, timestamp, join or fabricated existing source bytes.

Analyst pins exact current public surface/JSON placement/compatibility, formula
version, input/break order, deterministic qualifying-triple witness, same-period
report parity, privacy and supported-existing-DB/report-only behavior. Preserve
accepted source-state/retention limitations; #33 does not silently implement
#13's OpenRig generation/replay or universal gone-source detection. Discover
insufficient provenance explicitly rather than changing metrics to fit it.
